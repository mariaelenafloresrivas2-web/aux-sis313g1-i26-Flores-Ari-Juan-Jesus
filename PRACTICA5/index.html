PRÁCTICA N 5 - JAVASCRIPT

1.- Formas de conectar HTML con JavaScript

Existen dos formas principales de conectar un archivo HTML con JavaScript.

a.- JavaScript Interno

<script>
    alert("Hola Mundo");
</script>

b.- JavaScript Externo

<script src="script.js"></script>

2.- Visualizar resultados en consola

  1. Abrir el navegador.
  2. Ingresar al HTML.
  3. Presionar F12.
  4. Ir a la pestaña Consola.
  5. Usar console.log().
console.log("Hola Mundo");

3.- Variables en JavaScript

Las variables almacenan información dentro del programa.

var

var nombre = "Juan";

let

let edad = 20;

const

const PI = 3.1416;

Actualmente no se recomienda usar var porque puede causar errores.
